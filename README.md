# Universal Gacha Simulator

这是一个使用 Unity 6 开发的通用抽卡模拟器。当前仓库包含卡牌目录、卡包概率、保底、收藏库存、本地/云端存档以及远程 Addressables 内容下载的基础模块。

项目目前处于“通用抽卡核心”阶段，宝可梦卡牌只作为未来可插拔的数据源，不应写死在核心规则中。
